# Required OMA bulk files

Supply these three files from the same OMA release:

- `oma-uniprot.txt.gz`
- `oma-groups.txt.gz`
- `oma-seqs.fa.gz`

Keep original files and release/download records. Preparation records SHA-256 checksums. You may keep large files outside the repository and pass their folder with `--oma-dir`. They were not included in the uploaded archive, so they are not bundled in this add-on.
